# Тестовый набор для скила `docx-to-pdf`

## Назначение
Тестирование качества экспорта и точности рендеринга скрипта `scripts/docx_to_pdf.py` из плагина `docx-tools`.

## Планируемые тестовые сценарии:
1. **Конвертация одиночного документа через Word COM**: проверка нативного экспорта в Windows с установленным MS Word.
2. **Фоллбэк на LibreOffice headless**: проверка конвертации при отсутствии активного процесса Word COM.
3. **Пакетная конвертация каталога (`--batch`)**: одновременная конвертация нескольких файлов в целевую папку.
4. **Визуальная валидация**: сверка рендеринга страниц, отступов и встроенных векторных/растровых изображений.
