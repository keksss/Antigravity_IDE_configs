# Тестовый набор для скила `docx-to-pdf`

Комплексный набор автоматизированных тестов для скила конвертации документов Microsoft Word (`.docx`) в формат Portable Document Format (`.pdf`) с сохранением авторской верстки, колонтитулов, векторных и растровых фигур, таблиц и шрифтов.

---

## Назначение

Набор тестов обеспечивает верификацию скрипта [`docx_to_pdf.py`](file:///c:/Users/KonstantinIvanov2/Project/Antigravity_IDE_configs/.agents/plugins/docx-tools/skills/docx-to-pdf/scripts/docx_to_pdf.py), предотвращает регрессии и проверяет все функциональные сценарии:
1. **Нативная конвертация Microsoft Word COM:** рендеринг документа в Windows с помощью изолированного подпроцесса Word COM с таймаутом и контролем зависаний.
2. **Выбор движков и фоллбэк:** работа режимов `--engine auto`, `--engine word`, `--engine libreoffice`, валидация параметров CLI и понятные сообщения об ошибках при отсутствии движка.
3. **Кастомные пути и вложенные каталоги:** автоматическое создание глубоко вложенных папок (`-o path/to/nested/doc.pdf`).
4. **Пакетная конвертация каталогов:** одновременная обработка нескольких `.docx` документов в папке с помещением готовых `.pdf` в целевой каталог.
5. **Защита от перезаписи:** блокировка случайной перезаписи без `--force` и корректная перезапись при указании `--force` (`-f`).
6. **Фильтрация lock-файлов Word:** игнорирование временных служебных файлов (`~$*.docx`).
7. **Устойчивость к ошибкам (Edge cases):** корректная обработка пустых файлов (0 байт), поврежденных zip-архивов и отсутствующих файлов с кодом возврата `1` и без необработанных исключений Python.
8. **Реальные корпоративные образцы:** сквозная конвертация файлов из каталога `files_examples/` (`file-sample_1.docx`, `file-sample_2.docx`, `file-sample_3.docx`).
9. **Контроль качества PDF:** глубокая инспекция с помощью библиотеки `PyMuPDF` (`fitz`): проверка числа страниц, целостности кириллических глифов, текста таблиц и наличия растрированных изображений.

## Описание тестовых сценариев

| Сценарий | Название | Что проверяется |
| :--- | :--- | :--- |
| **01** | `Single File Word COM` | Нативная конвертация документа с форматированным текстом, таблицами и графикой через Microsoft Word COM (`--engine word`). Валидация заголовка `%PDF-` и ненулевого размера. |
| **02** | `Engine Selection` | Проверка авто-выбора движка (`--engine auto`), отклонения некорректных движков через `argparse` и поведения при вызове `--engine libreoffice`. |
| **03** | `Custom Output & Nested Dirs` | Преобразование с флагом `-o` в глубоко вложенный несуществующий путь; проверка автосоздания родительских директорий. |
| **04** | `Batch Conversion` | Пакетная конвертация каталога из нескольких `.docx` документов в целевой каталог с верификацией каждого созданного PDF. |
| **05** | `Overwrite Protection & Force` | Предотвращение случайной перезаписи существующего PDF файла без `--force` и успешная перезапись с флагом `--force`. |
| **06** | `Lock Files Filtering` | Игнорирование временных lock-файлов Word (`~$*.docx`) при пакетном обходе и отклонение при явной передаче. |
| **07** | `Edge Cases & Error Handling` | Обработка 0-байтовых файлов, поврежденных псевдо-docx и несуществующих файлов. Проверка отсутствия необработанных tracebacks. |
| **08** | `Real-World Samples Suite` | Конвертация реальных документов (`file-sample_1.docx`, `file-sample_2.docx`, `file-sample_3.docx`) со сложной структурой. |
| **09** | `PDF Quality & Content Inspection` | Валидация через `PyMuPDF`: совпадение количества страниц (многостраничность), корректность извлечения кириллического текста (без искажения кодировки), наличие таблиц и растрированных картинок в структуре PDF. |

## Запуск тестов

### 1. Автономный запуск через `uv` (рекомендуется):
```powershell
uv run tests/docx-tools/docx-to-pdf/run_tests.py
```

### 2. Запуск через общий мастер-раннер репозитория:
```powershell
# Для всех скилов плагина docx-tools
uv run tests/run_all.py --plugin docx-tools

# Полный прогон всех плагинов репозитория
uv run tests/run_all.py
```
