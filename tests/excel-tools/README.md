# Тестовый набор для плагина `excel-tools`

## Назначение
Тестирование скилов и скриптов плагина `excel-tools` (работа с книгами Excel, формулами, стилями, графиками и сводными таблицами).

## Планируемые направления тестирования:
- Чтение и парсинг `.xlsx` / `.xlsm` без повреждения макросов.
- Точечная модификация ячеек и диапазонов.
- Генерация отчетов по шаблонам.
- Валидация через Excel COM / openpyxl / xlwings.
