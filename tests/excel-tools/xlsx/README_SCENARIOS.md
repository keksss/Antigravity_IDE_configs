# Тестовый набор скилла `xlsx` (`excel-tools`)

Комплексный автоматизированный набор тестов для проверки работоспособности, надежности и соблюдения правил целостности скилла [`xlsx`](file:///c:/Users/kekss/Project/Antigravity_IDE_configs/.agents/plugins/excel-tools/skills/xlsx) и плагина [`excel-tools`](file:///c:/Users/kekss/Project/Antigravity_IDE_configs/.agents/plugins/excel-tools).

---

## Матрица тестовых сценариев (16 сценариев)

| № | Сценарий | Категория | Описание и проверяемые аспекты |
|---|---|---|---|
| **01** | `inspect_summary` | Инспекция | Проверка режима `--mode summary` утилиты `excel_inspect.py` на реальных файлах (`sample1.xlsx`, `sample2.xlsx`, `sample3.xlsx`): определение листов, размеров, числа строк/колонок. |
| **02** | `inspect_preview` | Инспекция | Проверка режима `--mode preview`: генерация Markdown-таблицы с буквенными обозначениями колонок `[A]`, `[B]` и номерами строк, лимиты строк (`--max-rows`). |
| **03** | `inspect_csv_tsv` | Инспекция | Автоматическое определение разделителей для файлов `.csv` и `.tsv`, корректное отображение табличного превью в терминале. |
| **04** | `inspect_formulas` | Инспекция | Проверка режима `--mode formulas`: поиск и точный сбор всех ячеек с формулами (`=SUM(...)`, `=AVERAGE(...)`, `=IF(...)`) с координатами ячеек. |
| **05** | `financial_model_styling` | Оформление | Создание финансовой модели с нуля с соблюдением правил [`excel-integrity.md`](../../.agents/plugins/excel-tools/rules/excel-integrity.md): синий шрифт для вводных данных, черный для формул, мягкая желтая заливка, формат валют `$#,##0`, проценты как дроби, сетка таблицы. |
| **06** | `recalc_zero_errors` | Пересчет | Запуск универсального пересчетчика `recalc.py` на корректной модели. Проверка статуса `success`, нулевых ошибок (`total_errors: 0`), сохранения кэшированных значений ячеек. |
| **07** | `recalc_error_detection` | Диагностика | Проверка обнаружения ошибок формул: намеренное внедрение `#DIV/0!`, `#NAME?`, `#REF!`. Проверка статуса `errors_found` и детализации координат в `error_summary`. |
| **08** | `post_2007_functions` | Совместимость | Использование функций Excel после 2007 года с префиксом `_xlfn.` (`_xlfn.TEXTJOIN`, `_xlfn.CONCAT`, `_xlfn.IFS`). Проверка успешного пересчета без ошибок `#NAME?`. |
| **09** | `cross_sheet_references` | Многолистовые книги | Связи между несколькими листами с пробелами и спецсимволами в именах (`'Assumptions & Inputs'!$B$2`). Проверка корректного вычисления формул сквозь листы. |
| **10** | `external_link_protection` | Безопасность данных | Обнаружение внешних связей (`='[External.xlsx]Sheet'!A1`). Блокировка пересчета без ключа `--force` для защиты кэша; принудительный пересчет с `--force`. |
| **11** | `inplace_edit_backup` | Безопасность | Модификация существующего файла с обязательным созданием `.bak`-бэкапа. Проверка идентичности бэкапа оригиналу и корректности изменений в целевом файле. |
| **12** | `xlsm_macro_handling` | Макросы | Проверка открытия и сохранения книги с поддержкой макросов (`.xlsm`) с флагом `keep_vba=True`, сохранение бинарных модулей VBA. |
| **13** | `merged_cells_and_edge_cases` | Граничные случаи | Объединенные ячейки (запись только в левый верхний угол), отображение нулей как `-`, форматирование больших чисел. |
| **14** | `engine_selection` | Архитектура | Валидация аргументов `--engine auto`, `--engine excel`, `--engine libreoffice`: переключение движков и информативная обработка при отсутствии движка. |
| **15** | `excel_com_validation` | Валидация Excel | Открытие сгенерированных книг через нативный Microsoft Excel COM (`win32com.client`), проверка отсутствия диалоговых окон о повреждении файла, сверка рассчитанных значений ячеек. |
| **16** | `json_html_export` | Экспорт для LLM | Конвертация в форматы JSON (records для аналитики, json-grid с координатами ячеек и формулами) и семантический HTML с трансляцией объединенных ячеек в `colspan`/`rowspan`. |

## Запуск тестов

### Запуск через общий раннер тестов репозитория:
```bash
uv run tests/run_all.py --plugin excel-tools
```

### Автономный запуск раннера скилла `xlsx`:
```bash
uv run tests/excel-tools/xlsx/run_tests.py
```

### Запуск конкретного сценария по фильтру:
```bash
uv run tests/excel-tools/xlsx/run_tests.py --filter 05
uv run tests/excel-tools/xlsx/run_tests.py --filter recalc
```
