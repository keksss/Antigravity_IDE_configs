# Сценарий 15: Валидация через Microsoft Excel COM

В этом сценарии книга открывается непосредственно в живом процессе Microsoft Excel через Windows COM-интерфейс (`win32com.client`).

## Проверенные параметры:
- **Версия Excel:** 16.0
- **Выручка B4 (FY2024):** 1,250,000.00 руб.
- **Выручка C4 (FY2025, рост 12.5%):** 1,406,250.00 руб.
- **Валовая прибыль B6:** 625,000.00 руб.
- **Штамп аудита:** Записан в строку 8 книги `excel_com_verified_model.xlsx`.
- **Отчет аудита:** Сохранен в `excel_com_audit.json`.
