# Сценарий 10: Защита внешних ссылок (External Links Protection)

## Описание сценария
Когда книга Excel ссылается на внешнюю книгу (`=[source_budget.xlsx]Sheet1!$B$1`), автоматический пересчет формул без ведома пользователя может привести к затиранию кешированных значений (например, записью `#REF!` или `0`, если внешняя книга недоступна в окружении пересчета).

Кроме того, библиотека `openpyxl` имеет критическое ограничение: при вызове `openpyxl.save()` на файле с внешними связями она повреждает структуру `/xl/externalLinks/externalLink1.xml`, из-за чего Excel при открытии выдает предупреждение о восстановлении (`[RecoveredExternalLink1]`).

## Поведение в `recalc.py`:
- **Без `--force`:** Скрипт сканирует формулы, обнаруживает ссылки на внешние книги и блокирует пересчет с кодом ошибки, требуя явного подтверждения пользователя.
- **С `--force`:** Выполняет пересчет через родной движок Microsoft Excel COM без повреждения XML-структур.

## Результат
Файлы `source_budget.xlsx` и `consolidated_report.xlsx` валидны на 100% и открываются в Microsoft Excel без предупреждений о повреждении или необходимости восстановления.
