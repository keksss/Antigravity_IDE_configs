# Сценарий 16: Экспорт в JSON и HTML для LLM

В этом сценарии проверяется экспорт табличных данных из Excel в форматы, оптимизированные для потребления языковыми моделями (LLM):

1. **`model_records.json`:** Табличные данные в виде массива записей (records) со словарем формул (`formulas`). Идеален для аналитики и RAG.
2. **`model_grid.json`:** Координатная сетка ячеек (`json-grid`), где для каждой ячейки сохранено ее значение (`v`) и формула (`f`). Незаменим для точечного планирования правок формул моделью.
3. **`merged_report.html`:** Семантическая HTML-таблица с автоматической трансляцией диапазонов объединения ячеек в атрибуты `colspan` и `rowspan`.
