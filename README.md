# Antigravity IDE Configs & Plugins

Коллекция плагинов, скилов (навыков) и правил для расширения возможностей **Google Antigravity IDE**.

Репозиторий спроектирован с упором на модульность, высокую переносимость (strict portability), сохранение целостности сложных форматов документов и автоматизированное тестирование.

---

## 📦 Каталог плагинов

### 1. [`docx-tools`](file:///.agents/plugins/docx-tools/README.md)
Полнофункциональный набор инструментов для работы с документами Microsoft Word (`.docx`) без повреждения стилей, колонтитулов и встроенных изображений.

| Скил | Назначение | Ключевые скрипты |
| :--- | :--- | :--- |
| **`docx-editor`** | Инспекция структуры, замена текста (в т.ч. multi-run), вставка абзацев по якорям со стилями, добавление строк в таблицы с клонированием границ, шаблонизация Jinja2 | `docx_inspect.py`, `docx_edit.py`, `docx_render.py` |
| **`docx-to-markdown`** | Конвертация `.docx` в Markdown с распаковкой всех картинок в `media/` и сохранением таблиц | `docx_to_md.py` |
| **`docx-to-pdf`** | Высокоточный экспорт `.docx` в PDF через Microsoft Word COM (или LibreOffice headless) | `docx_to_pdf.py` |
| **`markdown-to-docx`** | Генерация презентационных `.docx` из Markdown с поддержкой корпоративных шаблонов | `md_to_docx.py` |

### 2. `excel-tools` *(В разработке)*
Плагин для работы с электронными таблицами Microsoft Excel (`.xlsx`, `.xlsm`): чтение, модификация ячеек, генерация отчетов по шаблонам, формулы и графики.

## 🚀 Установка и использование плагинов

### Вариант 1: На уровне рабочего пространства (Workspace)
Склонируйте репозиторий или скопируйте нужный плагин в папку `.agents/plugins/` вашего проекта:
```bash
cp -r .agents/plugins/docx-tools /path/to/your/project/.agents/plugins/
```

### Вариант 2: Глобальная установка (на всю систему)
Скопируйте плагин в глобальную конфигурацию Antigravity:
```bash
cp -r .agents/plugins/docx-tools ~/.gemini/config/plugins/
```

После этого скилы станут доступны во всех чатах и сессиях Antigravity IDE.

## 🧪 Тестирование

Для запуска тестов используется пакетный менеджер [`uv`](https://docs.astral.sh/uv/):

```bash
# Запуск всех доступных тестов репозитория
uv run tests/run_all.py

# Запуск тестов конкретного плагина
uv run tests/run_all.py --plugin docx-tools

# Запуск изолированного набора тестов скила docx-editor (16 сценариев)
uv run tests/docx-tools/docx-editor/run_tests.py
```

### Результаты валидации `docx-editor` (16 сценариев):
- **100% PASS**: Проверена замена текста (в теле, таблицах, multi-run), наследование стилей параграфов, сохранение границ таблиц при добавлении строк, шаблонизация Jinja2, удаление титульных листов, работа колонтитулов с логотипами и вставка картинок внутрь ячеек таблиц.
- **Microsoft Word 16.0 COM**: Все 12 сгенерированных документов прошли нативную валидацию в MS Word без единой ошибки и экспортированы в PDF.
