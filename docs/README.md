# Документация платформы Antigravity Customizations

В данном разделе собраны официальные руководства и спецификации по созданию расширений (кастомизаций) для Google Antigravity IDE.

---

## Разделы документации

1. 🔌 **[Plugins (Плагины)](./Plugins.md)**
   - Пространства имён для объединения скилов, правил, MCP-серверов и хуков в единые переносимые пакеты.
   - Спецификация файла `plugin.json` и правила загрузки (на уровне workspace или глобально).

2. 🧠 **[Skills (Скилы)](./Skills.md)**
   - Описание специализированных возможностей агента.
   - Спецификация файла `SKILL.md`, YAML frontmatter, прогрессивная подгрузка контекста и организация вспомогательных скриптов (`scripts/`, `references/`).

3. 📜 **[Rules (Правила)](./Rules.md)**
   - Поведенческие ограничения, архитектурные принципы и стилевые руководства.
   - Правила на уровне проекта (`.agents/rules/`) и правила плагинов (`plugins/<plugin>/rules/`).

4. 🌐 **[MCP (Model Context Protocol)](./MCP.md)**
   - Интеграция с внешними инструментами, базами данных и сервисами через протокол MCP (`mcp_config.json`).

5. ⚡ **[Hooks (Хуки)](./Hooks.md)**
   - Автоматический запуск скриптов и команд при возникновении определенных событий в IDE (`hooks.json`).
