# Outlook Tools Plugin (`outlook-tools`)

Плагин для Antigravity IDE, предоставляющий AI-агенту полный набор инструментов для взаимодействия с настольным почтовым клиентом **Microsoft Outlook** (Classic Desktop) через Windows COM (MAPI).

---

## 🚀 Возможности плагина

1. **`outlook-folders`**: Навигация по структуре папок, аккаунтам (OST/PST) и просмотр счетчиков непрочитанных писем.
2. **`outlook-mail`**: Поиск сообщений по фильтрам (Jet/DASL), чтение содержимого и вложений, полный жизненный цикл черновиков с редактированием по `EntryID`, контролируемая отправка сообщений.
3. **`outlook-calendar`**: Просмотр расписания на день/неделю/период с учетом повторяющихся событий, поиск встреч, создание событий, онлайн-встреч **Microsoft Teams** и безопасное управление приглашениями.
4. **`outlook-contacts`**: Быстрый поиск в личной адресной книге и корпоративном справочнике Exchange (**Global Address List — GAL**).

---

## 🛡️ Двухуровневая система безопасности

Плагин реализует строгую модель защиты от непреднамеренных или деструктивных действий:

1. **Уровень 1 (Поведенческий / `rules/outlook-safety.md`):**
   - Агент **никогда** не отправляет письмо сразу. Сначала создается черновик (`--draft`), пользователю в чат выводится карточка сообщения и запрашивается прямое текстовое согласие на отправку.
   - Аналогично, отмена встреч (`--cancel`) и удаление данных требуют явного подтверждения.
2. **Уровень 2 (Системный перехватчик / `hooks.json` & `hooks/safety_check.py`):**
   - На уровне среды Antigravity зарегистрирован хук `PreToolUse` для инструмента `run_command`.
   - При обнаружении флагов `--send`, `--delete` или `--cancel` хук принудительно возвращает `force_ask`, вызывая системное диалоговое окно подтверждения пользователя перед физическим запуском команды.

## 📦 Архитектура и структура каталогов

```
plugins/outlook-tools/
├── plugin.json                         # Манифест плагина
├── hooks.json                          # Конфигурация системного перехватчика PreToolUse
├── README.md                           # Документация плагина
├── hooks/
│   └── safety_check.py                 # Скрипт проверки команд на критические флаги (force_ask)
├── rules/
│   └── outlook-safety.md               # Правила безопасной работы и подтверждения действий
└── skills/
    ├── outlook-folders/
    │   ├── SKILL.md
    │   └── scripts/
    │       └── outlook_folders.py      # Дерево папок и статистика хранилищ
    ├── outlook-mail/
    │   ├── SKILL.md
    │   └── scripts/
    │       ├── mail_search.py          # Поиск и фильтрация писем
    │       ├── mail_read.py            # Чтение письма, метаданных и вложений
    │       └── mail_compose.py         # Создание черновика, редактирование по ID, отправка
    ├── outlook-calendar/
    │   ├── SKILL.md
    │   └── scripts/
    │       ├── calendar_read.py        # Просмотр событий календаря и онлайн-ссылок
    │       └── calendar_manage.py      # Создание встреч (Teams) и управление расписанием
    └── outlook-contacts/
        ├── SKILL.md
        └── scripts/
            └── contacts_search.py      # Поиск контактов (локальные + Exchange GAL)
```

## ⚙️ Требования и запуск

- **Операционная система:** Windows 10/11 с установленным классическим клиентом Microsoft Outlook (Microsoft 365, Office 2016/2019/2021).
- **Изоляция Python:** Все скрипты оформлены в соответствии с **PEP 723** (inline metadata) и запускаются через **`uv`**:
  ```bash
  uv run scripts/<script_name>.py [args]
  ```
- **Зависимости:** `pywin32>=306`, `python-dateutil>=2.8.2` (устанавливаются автоматически через `uv`).
